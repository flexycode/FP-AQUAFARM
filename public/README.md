# FP AQUAFARM - Media Directory Guide

### Hero Background Video
Place your looping farm footage file here:
`/public/videos/farm-hero.mp4`

- **Recommended specs**: MP4 (H.264), 1080p, 24-30 fps, muted audio track for browser autoplay compatibility.

### Farm Photography
Place your photography shots here:
`/public/images/gallery/`

Update the paths inside `src/data/farmData.ts` under `GALLERY_ITEMS`.
