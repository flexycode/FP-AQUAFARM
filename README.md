# FP AQUAFARM 🌊🦀

> Premium, sustainable aquaculture from the coastal estuary basins of Minanga Weste, Buguey, Cagayan.

Welcome to the official web platform for **FP AQUAFARM**. This application serves as the digital storefront and informational hub for our aquaculture operations, showcasing our premium seafood harvests, bio-secure farming practices, and wholesale contact channels.

## 🐟 Our Harvest
- **Pond-Fattened Mud Crab (*Scylla serrata*)**: Premium, naturally-fattened crabs with solid carapace and massive claws.
- **Giant Tiger Prawns (*Penaeus monodon*)**: Sustainably farmed, zero-antibiotic premium prawns.
- **Premium Silver Milkfish (*Chanos chanos*)**: Flash-chilled, naturally-fed milkfish known for exceptional taste.

## 🚀 Tech Stack
This project is built with modern frontend technologies to ensure a fast, responsive, and visually engaging user experience:
- **Framework**: [React 18](https://react.dev/) powered by [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🛠️ Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/fp-aquafarm.git
   cd fp-aquafarm
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:3000`.

4. **Build for production**
   ```bash
   npm run build
   ```
